# MyApp - SaaS Dashboard Project

A responsive front-end web application built as part of an 8-week internship, demonstrating core web development skills using HTML5, CSS3, JavaScript, and Tailwind CSS.

## Features
- Responsive landing page with navigation and hero section
- Signup form with client-side validation
- Reusable UI components (buttons, cards) styled with Tailwind CSS
- User dashboard with dynamic data fetched from a REST API
- Simple login system using localStorage for client-side session state
- Tested across multiple browsers (Chrome, Edge)

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
- Tailwind CSS (via CDN)
- Git & GitHub for version control

## Pages
| File | Description |
|------|-------------|
| index.html | Landing page |
| form.html | Signup form with validation |
| components.html | Reusable UI components |
| dashboard.html | User dashboard with API data |
| login.html | Login page with localStorage session |

## How to Run
1. Clone or download this repository
2. Open the project folder in VS Code
3. Install the "Live Server" extension
4. Right-click `index.html` → "Open with Live Server"
